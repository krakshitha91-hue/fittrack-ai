# FitTrack AI – AI-Powered Fitness Tracker

**A full-stack fitness tracking application with AI-powered food analysis.**

FitTrack AI helps users track daily nutrition, monitor workouts, and manage fitness goals. It integrates Google Gemini AI to analyze food images and estimate nutritional information.

🌐 **Live Application:** https://fittrack-ai-puce.vercel.app/

💻 **GitHub Repository:** https://github.com/krakshitha91-hue/fittrack-ai

---

## 🚀 Key Features

- **User Authentication:** User registration and login with JWT authentication.
- **Nutrition Tracking:** Add, update, and delete meals while monitoring daily calorie intake.
- **AI Food Analysis:** Upload food images to identify food and estimate calories and nutritional values using Google Gemini AI.
- **Workout Tracking:** Record workout activities, duration, and calories burned.
- **Fitness Goals:** Manage daily fitness and nutrition goals.
- **Interactive Dashboard:** View nutrition and workout information in one place.
- **Personalized Data:** Store and retrieve individual user information from MongoDB.

## 🏗️ Application Architecture

**Frontend → Backend API → Database / AI Service**

- **Frontend:** React application provides the user interface and communicates with backend APIs.
- **Backend:** Express.js handles authentication, business logic, and API requests.
- **Database:** MongoDB stores user profiles, meals, workouts, and fitness goals.
- **AI Service:** Google Gemini API analyzes uploaded food images and estimates nutritional information.
